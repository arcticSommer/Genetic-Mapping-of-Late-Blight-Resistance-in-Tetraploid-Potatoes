# Genetic Mapping of Resistance to Phytophthora infestans Genes in Tetraploid Potatoes’

This github repository contains all code that has been used in the project. 

1. Before you run the code, you must make your own working directory and create the following folders within it:
- data
- plots
- results

2. The following datasets are attached in Digital Eksamen, and they must be stored in your data folder, as the datasets are necessary to run the code:
- MASPOT_NDV_pt.RData
- MASPOT_RST_pt.RData
- parents_rst.txt
- snppos.RData
- MASPOT_F1_gt.RData

3. Remember to change setwd() in the code to your own working directory.

You are ready to go!
